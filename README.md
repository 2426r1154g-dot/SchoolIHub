# SchoolHub

学生向けコミュニティサイトの本格版プロトタイプ。

## 機能
- Firebase Authenticationによるログイン / 新規登録
- リアルタイム掲示板
- いいね（1ユーザー1回、取り消し可能）
- 自分の投稿だけ削除
- 質問箱 / 回答
- イベント管理
- 勉強時間記録
- 勉強時間ランキング
- マイページ
- ダークテーマ
- PC / スマホ対応

## 起動
Firebaseの設定を app.js に入れて、静的ホスティングへアップロード。

詳細は SETUP.md を参照。

- 勉強タイマー（開始 / 一時停止 / リセット / 勉強記録への追加）
